ЭТО ОБНОВЛЕНИЕ ТЕКУЩЕГО ПРАЙС-БОТА, А НЕ ВТОРОЙ ПРОЕКТ.

1. Загрузи эти файлы в текущий GitHub repo.
2. Railway service не создавай заново.
3. Старые Variables оставь.
4. Добавь:
   CONTROL_BOT_TOKEN=<токен бота от BotFather>
   ADMIN_ID=<твой Telegram user id>
   STATE_DIR=/data
5. Start Command: python launcher.py
6. SETUP_MODE=false

Один процесс теперь одновременно:
- запрашивает прайс у поставщика;
- делит на 15/16/17 + SIM/eSIM;
- редактирует постоянные сообщения;
- показывает навигационные кнопки;
- управляется через отдельный Telegram Bot API интерфейс.

# Price Bot — merged version

Один отдельный сервис:

- Telethon сам запрашивает прайс у бота поставщика.
- Управляющий Telegram-бот позволяет запускать/останавливать синхронизацию.
- Интервал меняется кнопками: 5 / 15 / 30 / 60 / 120 минут или вручную.
- Кнопка "Запросить сейчас" обновляет прайс сразу.
- Прайс делится на 6 постоянных блоков:
  - iPhone 15 SIM
  - iPhone 15 eSIM
  - iPhone 16 SIM
  - iPhone 16 eSIM
  - iPhone 17 SIM
  - iPhone 17 eSIM
- Все эти сообщения создаются один раз, затем только редактируются.
- Внизу создаётся навигация с кнопками на нужные сообщения.
- Если поставщик закрыт, цены исчезают из блоков, но сами сообщения остаются.
- Внизу появляется "Продажи временно закрыты".
- После открытия это сообщение удаляется, а цены возвращаются в те же сообщения.
- Доступ к управляющему боту есть только у ADMIN_ID.

## Railway Variables

Обязательно:

```text
API_ID=
API_HASH=
SESSION_STRING=
SUPPLIER_BOT=@...
TARGET_CHANNEL=@...      # либо -100...
REQUEST_TEXT=/start
BUTTON_PATH=Прайс
CONTROL_BOT_TOKEN=       # токен отдельного бота от BotFather
ADMIN_ID=                # твой Telegram user ID
POLL_SECONDS=1800
STATE_DIR=/data
SETUP_MODE=false
```

Start Command:

```text
python launcher.py
```

## Railway Volume

Чтобы настройки управляющего бота (интервал, выключенные блоки и т.п.)
не терялись после redeploy, рекомендуется подключить Railway Volume
и смонтировать его в:

```text
/data
```

Если state потеряется, сами сообщения прайса не задублируются:
сервис пытается найти старые блоки в канале по их заголовкам.

## Управляющий бот

Напиши `/start` боту, чей токен указан в `CONTROL_BOT_TOKEN`.

Меню:

- Запустить / остановить
- Запросить сейчас
- Интервал
- Блоки
- Статус

## Парсер

Парсер понимает строки с явными `SIM` / `eSIM`, а также заголовки разделов.
Если конкретный прайс поставщика оформлен необычно, его можно точно подогнать
по одному реальному примеру прайса.


## Как ставить вместо текущего прайс-бота

Это НЕ второй проект.

Просто замени файлы в текущем GitHub-репозитории прайс-бота на файлы из этого архива.
Railway service остаётся тот же самый.

Существующие Variables сохраняются:

```text
API_ID
API_HASH
SESSION_STRING
SUPPLIER_BOT
TARGET_CHANNEL
REQUEST_TEXT
BUTTON_PATH
POLL_SECONDS
SETUP_MODE
SETUP_KEY
```

Добавить нужно только:

```text
CONTROL_BOT_TOKEN=
ADMIN_ID=
STATE_DIR=/data
```

Start Command остаётся:

```text
python launcher.py
```

После `SETUP_MODE=false` launcher запускает `main.py`, а `main.py` одновременно:
1. запускает Telethon для поставщика;
2. запускает управляющего Telegram-бота;
3. держит таймер синхронизации;
4. обновляет блоки прайса в канале.


## Права для работы

В TARGET_CHANNEL:

- аккаунт из `SESSION_STRING` должен быть участником/админом и уметь публиковать и редактировать;
- бот из `CONTROL_BOT_TOKEN` должен быть админом, чтобы создавать навигацию с inline-кнопками.

Если управляющий бот не админ, прайс всё равно должен синхронизироваться,
а в логах появится предупреждение о навигации вместо падения всего сервиса.


## Multi-message price fix

Большой `/prices` может приходить несколькими Telegram-сообщениями.
Эта версия собирает весь пакет сообщений после запроса и только потом парсит его.

Для текущего формата поставщика:
- `17 ... (eSim)` -> eSIM
- `17 ... (1Sim+eSim)` -> SIM
- `15/16` с флагом 🇺🇸 -> eSIM
- остальные `15/16` -> SIM

Строки 12/13/14 пока намеренно не входят в блоки 15/16/17.


## График и порядок блоков

- Рабочее время: 10:00–20:00 МСК.
- В 20:00 цены автоматически скрываются.
- Ночью поставщик не запрашивается.
- В 10:00 при включённой синхронизации сразу запрашивается свежий прайс.
- Статус поставщика: открыт / закрыт / ошибка связи / ещё не проверен.
- Все времена в управляющем боте показываются по МСК.

В `⚙️ Блоки` есть `↕️ Порядок блоков`.
Стрелками можно выставить любой порядок, затем нажать `✅ Применить порядок`.
Telegram не умеет физически переставлять старые сообщения, поэтому применение
порядка один раз удаляет только сообщения прайса и создаёт их заново в выбранном порядке.
После этого обычные обновления снова идут через редактирование.

# HI Price Bot — clean two-price rebuild

Один Railway service. Один Telegram user-account читает **ровно два** бота поставщиков и публикует единый прайс в канал.

## Что делает

1. Параллельно запрашивает `SUPPLIER_BOT` и `SUPPLIER_BOT_2`.
2. Читает обычные товарные строки с ценой в конце.
3. Полностью игнорирует `От N шт`, опт и служебные строки.
4. Сохраняет полное наименование поставщика: страну/флаг, память, цвет, SIM/eSIM/2SIM, CPO/ASIS, ремонтный/replacement, актив/предактив, год, код модели, размер и комплектацию.
5. Если одинаковый полный вариант есть у двух поставщиков — берёт меньшую закупочную цену.
6. После выбора закупки добавляет общую наценку.
7. Канальные сообщения создаются один раз и дальше **редактируются на месте**. Новый message_id появляется только если сообщения ещё нет/его удалили вручную или Telegram требует дополнительную часть из-за лимита 4096 символов.
8. Названия товаров публикуются в `<code>...</code>` отдельно от цены — в Telegram их удобно копировать как отдельный фрагмент.

## Открытие / закрытие

- До `WORK_START_HOUR=10` публикация открывается раньше только если **оба поставщика открыты**.
- С 10:00 МСК достаточно хотя бы одного открытого поставщика.
- Если оба поставщика закрылись — существующие сообщения не удаляются, а редактируются в состояние `Продажи закрыты`.
- Если один источник ошибся, корректный последний прайс не уничтожается. Если второй источник открыт — используется он.

## Управляющий бот

- ▶️ Запустить / ⏸ Остановить
- 🔄 Обновить сейчас
- ⏱ Интервал
- 💰 Наценка
- 📊 Статус двух поставщиков
- 🔐 Вход Telegram по номеру / коду / 2FA

`Остановить` прекращает автоматические запросы. Ручная кнопка `Обновить сейчас` остаётся доступной.

## Railway Variables

```text
API_ID=
API_HASH=
DATABASE_URL=

SUPPLIER_BOT=@supplier_bot_1
REQUEST_TEXT=/prices
BUTTON_PATH=
CLOSED_TEXT_1=В данный момент мы закрыты. Пожалуйста, дождитесь старта продаж.

SUPPLIER_BOT_2=@supplier_bot_2
REQUEST_TEXT_2=/prices
BUTTON_PATH_2=
CLOSED_TEXT_2=В данный момент мы закрыты. Пожалуйста, дождитесь старта продаж.

TARGET_CHANNEL=-1001234567890
CONTROL_BOT_TOKEN=
ADMIN_ID=

POLL_SECONDS=1800
WORK_START_HOUR=10
RESPONSE_TIMEOUT=35
SUPPLIER_QUIET_SECONDS=4.0
```

Telegram `StringSession`, наценка, интервал, статусы и channel `message_id` хранятся в PostgreSQL.

## Start Command

```text
python launcher.py
```

Никакого `start.sh` и `chmod` не нужно.
